## Clarity check — data philosophy (YES, we are aligned)

Same as Phase 0:

- Prefer **quick live APIs** (Open-Meteo forecast + historical archive / ERA5-Land via Open-Meteo).
- **No live Sentinel/NDVI API** in the mock. NDVI is slow/batch (GEE, Copernicus, Sentinel Hub) — not “click district → instant NDVI.”
- For biomass / compound-yield mock: use **weather-derived proxies** (GDD progress, heat-stress, water-stress, radiation) that literature links to pepper growth/yield — **not** real-time NDVI.
- SoilGrids / DEM / TWI: optional **pre-baked static** per district if easy; otherwise synthetic/static fallback labelled honestly (as Phase 0 did).
- Rankings / history percentiles: Open-Meteo **archive** multi-year pulls (or cached), not NDVI.
- Presentation mock + rule-based “environment conduciveness” argument — founder narrates; not production ML.

## L3 / L4 mock methods (research-informed proxies — subject to change)

### L3 Compound yield ≈ environmental biomass/yield conduciveness × quality band

Literature links pepper growth/yield to **GDD**, temperature extremes, water deficit severity/duration, and radiation/PAR-style terms — not only NDVI.

**Mock (quick data only):**

1. **Yield conduciveness 0–10** from current-season Open-Meteo features, e.g.  
   - GDD progress vs expected for stage  
   - Penalise severe heat-stress days / consecutive hot days  
   - Penalise severe dry spells **or** extreme wetness (waterlogging)  
   - Favour moderate soil moisture / moderate VPD windows  
2. Map Quality band → numeric factor (e.g. Below-normal 0.7, Normal 1.0, Above-normal 1.15).  
3. **CompoundYieldIndex = clamp(YieldConduciveness × QualityFactor, 0, 10).**

Argue: “environment more/less conducive to biomass accumulation and quality formation this season” — **not** “predicted kg/ha.”

### L4 Sourcing reliability proxy

Strategy: true label needs contracts; until then only an **explicitly labelled proxy**.

**Mock:** blend of inverted disease band, quality band, compliance (esp. EU if export), compound-yield index — e.g. higher when Low disease + Normal/Above quality + high India/EU readiness. Always label **“Regional risk proxy — not validated delivery reliability.”**
